# 📊 JMS Analyzer

A Flask-based web application that helps students analyze their skills against job market requirements and provides a personalized learning roadmap.

## 🚀 Features

- ✅ Skill Analysis
- ✅ Match Score Calculation
- ✅ Interactive Dashboard
- ✅ Plotly Skill Distribution Chart
- ✅ Personalized Learning Roadmap
- ✅ Professional UI using HTML & CSS

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Plotly
